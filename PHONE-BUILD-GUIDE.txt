بناء تطبيق مخزني باستعمال الهاتف فقط

1) افتح https://github.com من متصفح الهاتف وأنشئ حساباً أو سجّل الدخول.
2) اضغط + ثم New repository.
3) اكتب الاسم Makhzani واتركه Public لتسهيل خطوات الرفع، ثم Create repository.
4) افتح المستودع واضغط Add file ثم Upload files.
5) فك ضغط Makhzani-project-reviewed.zip على الهاتف أولاً، ثم ارفع محتويات المجلد Makhzani (وليس ملف ZIP نفسه). يجب أن يظهر app و build.gradle.kts و settings.gradle.kts و .github.
   إذا لم يظهر مجلد .github عند اختيار الملفات، أنشئه يدوياً من Add file > Create new file واكتب المسار:
   .github/workflows/android-apk.yml
   ثم الصق محتوى الملف android-apk.yml الموجود في مجلد المشروع.
6) اضغط Commit changes.
7) افتح تبويب Actions في المستودع. اختر Build Makhzani APK ثم Run workflow إذا لم يبدأ البناء تلقائياً.
8) انتظر حتى ينتهي التشغيل بعلامة خضراء. افتح آخر تشغيل، ثم انزل إلى Artifacts واضغط Makhzani-debug-APK لتنزيل ZIP.
9) افتح ZIP من التنزيلات واستخرج app-debug.apk.
10) اضغط ملف APK. إذا طلب Android السماح بالتثبيت من هذا المصدر، فعّل السماح للمتصفح أو مدير الملفات ثم أكمل التثبيت.

ملاحظات:
- البناء يتم على خوادم GitHub وليس على الهاتف.
- هذا APK تجريبي موقّع بمفتاح debug ومناسب للتثبيت الشخصي، وليس للنشر على Google Play.
- لا ترفع كلمات مرور أو مفاتيح توقيع خاصة إلى مستودع عام.
- إذا فشل البناء، افتح سجل التشغيل الأحمر وانسخ آخر جزء من رسالة الخطأ لإرساله للمساعدة.
